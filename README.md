# Dense Temporal Motion Retargeting for Legged Robots — project page

Source of the project page for the paper *Dense Temporal Motion Retargeting for Legged Robots*
(Jaeryeong Kim\*, Taerim Yoon\*, Jin Cheng, Sungjoon Choi, Stelian Coros;
[arXiv:2609.38617](https://arxiv.org/abs/2609.38617)), served via GitHub Pages at
<https://jaeryeongnicolekim.com/Dense-Temporal-Motion-Retargeting-For-Legged-Robots/>.
Code: <https://github.com/nicolejrkim/DTMR>.

Open `index.html`. All videos are simulation renders unless marked as real robot; the
`viewer*.html` pages are self-contained WebGL viewers. No tracking scripts, no external resources.
